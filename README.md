## Українська

Настільний перекладач, що передає мовлення голосовому агенту та виводить перекладений звук на вибраний пристрій або віртуальний кабель. Робочі мови та поведінка залежать від налаштувань агента й сервісу.

### Можливості

- Сценарії з ElevenLabs Agents та Fish Audio / LiveKit.
- Вибір джерела мікрофона й аудіовиходу, передавання звуку в онлайн-конференцію через віртуальний кабель.
- Текстовий супровід і діагностичні інструменти.
- Налаштування голосу відповідно до підтримки обраного провайдера.

### Перший запуск

1. Завантажте EXE з офіційної сторінки нижче.
2. Налаштуйте власні ключі та агента / акаунт для обраного сервісу.
3. Виберіть фізичний мікрофон та пристрій виведення.
4. Для конференції за потреби встановіть VB-Audio Virtual Cable: вихід програми — CABLE Input, мікрофон конференції — CABLE Output.
5. Перевірте звук і запустіть переклад.

**Голос-клон не входить до дистрибутива:** можливості голосу залежать від конфігурації провайдера. Використовуйте лише голоси, на які маєте необхідні права та згоду.

### Вимоги та конфіденційність

Windows x64, інтернет, відповідні аудіопристрої та власні доступи до обраних сервісів. Залежно від провайдера, користування API може бути платним; перевіряйте актуальні умови у провайдера. Інсталяція віртуального кабелю, якщо він потрібен, виконується окремо. Дані передаються стороннім сервісам для обробки.

Завантажуйте програму лише з [офіційної сторінки OverLeX](https://overlex.eu/uk/translators.html). В Issues опишіть версію Windows, кроки відтворення та очікуваний результат. **Не публікуйте API-ключі, токени, особисті дані або приватні записи розмов.**

## English

A Windows desktop translator that sends speech to a voice agent and routes translated audio to an output device or virtual audio cable. Supports ElevenLabs Agents and Fish Audio / LiveKit workflows, audio device selection and transcript display. Languages and voice behavior depend on your configured provider and agent.

[Download and requirements](https://overlex.eu/en/translators.html) · [Report an issue](https://github.com/OverLordY/OverLord-Desktop-Translator/issues/new)

Requires Windows x64, internet and your own credentials for the selected services. Third-party usage may be billed. Do not post API keys or private recordings in public issues.

## Deutsch

Ein Windows-Desktop-Übersetzer, der Sprache an einen Sprachagenten sendet und übersetztes Audio an ein Ausgabegerät oder virtuelles Audiokabel weiterleitet. Unterstützt ElevenLabs Agents und Fish Audio / LiveKit, Geräteauswahl und Transkriptanzeige. Sprachen und Stimmen hängen von Anbieter- und Agentenkonfiguration ab.

[Download und Voraussetzungen](https://overlex.eu/de/translators.html) · [Fehler melden](https://github.com/OverLordY/OverLord-Desktop-Translator/issues/new)

Erforderlich sind Windows x64, Internet und eigene Zugangsdaten für die ausgewählten Dienste. Drittanbieter können Gebühren berechnen. Bitte keine API-Schlüssel oder privaten Aufnahmen in öffentlichen Issues veröffentlichen.
